# Квиз по Гарри Поттеру

Живая игра: главный экран на компьютере/ТВ, игроки заходят с телефонов по QR-коду — без регистрации, с любого интернета. 80 вопросов, Патронусы между вопросами и животное факультета-победителя в финале.

- Открой сайт → «Открыть главный экран».
- Игроки сканируют QR-код на экране.
- Листай игру кнопкой или пробелом.

Связь идёт через бесплатный публичный MQTT-брокер (broker.emqx.io, запасной — broker.hivemq.com).
